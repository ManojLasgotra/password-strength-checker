# Password Strength Checker

This is a simple Python project that checks whether a password is Weak, Medium or Strong.

## Features
- Checks minimum length (8 characters)
- Detects uppercase and lowercase letters
- Detects numbers
- Detects special characters

## Purpose
This project was created to understand password security and authentication concepts used in cybersecurity.

## How it works
The program takes a password as input and applies security rules. 
Based on the conditions, it classifies the password as Weak, Medium or Strong.
