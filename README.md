# Password Strength Checker (Python)

This is a simple cybersecurity mini project that checks the strength of a user password.

The program analyzes the password based on:
- Length of password
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

Then it categorizes the password as:
Weak / Medium / Strong

## Purpose
Weak passwords are a major reason for hacking and unauthorized access.
This project helps understand how secure password policies work in authentication systems.

## Technologies Used
- Python
- Regular Expressions (re module)

## How to Run
1. Install Python
2. Download the project
3. Open terminal in project folder
4. Run command:

python password_checker.py

5. Enter any password to check its strength

## Example
Input:
manoj@2005

Output:
Password Strength: Weak
